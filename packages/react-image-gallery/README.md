# react-image-gallery

Unstyled, accessible image gallery primitives for React — in the style of [Radix UI](https://www.radix-ui.com/) and [Base UI](https://base-ui.com/).

> Status: scaffold only. Primitives have not been implemented yet.

## Installation

```bash
npm install react-image-gallery
# or
pnpm add react-image-gallery
# or
yarn add react-image-gallery
```

`react` and `react-dom` (>= 18) are peer dependencies.
